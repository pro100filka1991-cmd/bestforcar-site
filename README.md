# BestForCar — сайт

Одностраничный лендинг автоателье BestForCar (Алматы): перетяжка салона, авточехлы, курс-стажировка.

- `index.html` — вся страница (HTML + стили, без сборки).
- `images/` — фото работ.

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите `index.html`, `README.md` и папку `images/`.
2. Settings → Pages → Source: ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.
